# 02 - Design System

## Visual Reference

The `design/` directory in the project root contains the visual references for **The Chronicles**.

These files represent the intended visual direction and appearance of the application. They should be treated as the primary visual reference when implementing the frontend.

## Instructions for Implementation

Before implementing or modifying any UI:

1. Inspect the relevant files in the `design/` directory.
2. Use the provided screens as the reference for layout, spacing, typography, colors, imagery and component appearance.
3. Recreate the designs as closely as reasonably possible using React components and CSS.
4. Maintain visual consistency across all application screens.
5. Reuse shared styles and components instead of implementing the same visual elements differently in different places.
6. Use provided background images and other visual assets where appropriate.

## Design Direction

The overall visual identity should feel like a personal memory journal or scrapbook.

The intended aesthetic includes:

- Warm, aged parchment backgrounds.
- Hand-drawn pencil illustrations.
- Muted beige, brown and sepia colors.
- Elegant serif typography for headings and important text.
- Subtle handwritten typography for decorative accents.
- Paper-like surfaces, delicate borders and restrained shadows.
- A warm, nostalgic and intimate atmosphere.

The application should feel personal and timeless rather than like a generic SaaS dashboard.

## Important Rules

- Do not replace the established visual direction with a different design concept.
- Do not introduce arbitrary colors, fonts or visual styles.
- Do not sacrifice usability or accessibility to reproduce decorative details.
- Keep the interface consistent with the provided references.
- If a design detail is unclear or not covered by the references, use the closest consistent solution rather than inventing a new visual direction.
- Do not treat screenshots as finished UI assets. Recreate their layouts and interactions using actual application components.

The `design/` directory should be consulted throughout frontend development, not just during the initial implementation.
